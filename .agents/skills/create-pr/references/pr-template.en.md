# English PR template

Follow the repository title convention and describe the resulting change in English. Adapt the following body to the actual diff. Replace instructional text before posting. Omit unused optional sections; preserve repository-required fields. Small changes may use one or two sentences and validation results.

```markdown
## Summary
Describe the problem or trigger and resulting behavior. Explain implementation choices only when useful for review.

## Validation
- `command` — actual result.
- Relevant checks not run, and why.

## Related issues
Link confirmed related issues, if any.

## Screenshots
Attach available before/after screenshots for visual changes, if useful.

## Risks and follow-up
State material limitations, compatibility changes, or required follow-up, if any.
```

Write for a reviewer who has not read the conversation. Do not invent test results, issues, screenshots, or risks. Remove guidance and unused optional sections before posting.
