# 한국어 PR 템플릿

저장소 제목 규칙을 따르며 변경 결과가 드러나는 한국어 제목을 쓴다. 아래 본문을 실제 diff에 맞게 조정하고 게시 전에 안내 문장을 대체한다. 불필요한 선택 섹션은 생략하되 저장소 필수 항목은 유지한다. 작은 변경은 한두 문장과 검증 결과로 충분하다.

```markdown
## 변경 요약
문제 또는 발생 조건과 변경 후 동작을 설명한다. 리뷰에 도움이 될 때만 구현 선택의 이유를 덧붙인다.

## 검증
- `실행 명령` — 실제 결과.
- 관련 검증 중 미실행 항목과 이유.

## 관련 이슈
실제로 관련된 이슈가 있으면 연결한다.

## 스크린샷
시각적 변경에 유용하면 확보한 변경 전후 스크린샷을 첨부한다.

## 위험 및 후속 작업
실질적 제약, 호환성 변경 또는 필요한 후속 작업이 있으면 설명한다.
```

대화를 읽지 않은 리뷰어를 기준으로 작성한다. 검증 결과·이슈·스크린샷·위험을 지어내지 않는다. 게시 전에 안내 문장과 사용하지 않는 선택 섹션을 제거한다.
